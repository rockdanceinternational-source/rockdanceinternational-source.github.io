Up Rock 就是 Top Rock 吗？

Top Rock 是 b-boy 和 b-girl 下地之前站着跳的部分。Up Rock 是一门独立的斗舞，而且出现得更早：两位 rocker 正面对决，跳满整张唱片，随音乐即兴。下面是两者的区别。

区别一览

Up Rock Top Rock（breaking 中）
是什么 一种斗舞：两位 rocker 正面对决，随音乐即兴 b-boy 和 b-girl 下地之前站着跳的部分
动作 Freestyle、jerk 和 burn 一套动作的开场，在 b-boy 或 b-girl 的任何 Footwork、Freezes 和 Power Moves 组合之前
时长 整首歌 breaking 是在歌曲的 break 段上跳的（通常30到60秒）
斗舞方式 面对面，常在 Apache Line 里进行 围成圆圈
DJ 唱片混接、串在一起 切音和搓碟

我们的理解是：弄清每种舞蹈各自的特点。尊重，从理解差异开始。

Top Rock 是什么

一位两种舞都跳过的 rocker，把一套 breaking 动作讲成了一个故事：

b-boy 或 b-girl 怎样搭建一套 breaking 动作：先站着跳 Top Rock，再下地做 footwork，最后用一个 freeze 收尾。

按布鲁克林的说法，rocker 所说的 freestyle，就是 breaker 所说的 Top Rock。

名字在哪里交汇

两个词都源自 rock。很多早期舞者说，Up Rock 最早叫 rock 或 rocking，而布朗克斯也用 rocking 这个词。后来，两个名字交织在了一起。按布鲁克林的说法，Up Rock 从80年代中期开始衰落，只以一种改头换面的形式留存下来，叫 Top Rock，由 breaker 来跳。按布朗克斯的说法，1979年至1984年的 breaker 对 rocking 有自己的简化版，叫 Top Rocking 或 uprocking。这门舞本身是何时、为何改叫 Up Rock 的，请看 Up Rock 是什么？。

Top Rock 是 Up Rock 的一种吗？

Top Rock 来自 rocking。rocking 在先，舞步也更复杂；b-boy 和 b-girl 把这些舞步简化了来跳，因为 breaking 的复杂之处在地面上。

  • 简化版。 Top Rock 是 breaking 里跳的改版 Up Rock，是对 rocking 的模仿。rock 和 breaking 是两种不同的舞蹈，就像梅伦格和萨尔萨。2003年一个舞团的30周年传单上，把 Uprock 和 B-boy 列为两个独立的比赛项目。
  • 在 breaking 里。 breaker 们自己对 rocking 的简化版叫 Top Rocking 或 uprocking。有些 breaking 书籍和网站把 uprock 列为 breaking 的又一个元素；对 rocker 来说，rocking 在先。

Up Rock 与 downrock

Downrock，也写作 down rock、downrocking 或 floor rock，指在地面上或贴近地面跳的 rocking。它具体涵盖哪些动作，说法不一。

按布鲁克林的说法，downrocking 是当地对地面舞蹈的叫法，布朗克斯管它叫 breaking，并加入了旋转、滑行等动作，把它发展开来。布朗克斯的说法则把1975年至1979年布朗克斯舞团的 footwork 描述为四肢着地完成的舞步，后来被称为 downrocking。

breaker 能学 Up Rock 吗？

能，而且两边都有舞者跨界。要做好花时间的准备：在一位老前辈看来，breaking 学起来更快。动作见基本功页。

那么，Up Rock 就是 Top Rock 吗？

不是。Top Rock 是一套 breaking 动作的开场：在 Footwork、Freezes 和 Power Moves 之前站着跳的几步。Up Rock 是一门完整的舞蹈，有自己的斗舞、自己的音乐和自己的规则，从唱片的第一小节一直跳到最后一小节。是 Top Rock 出自 rocking，而不是反过来。
