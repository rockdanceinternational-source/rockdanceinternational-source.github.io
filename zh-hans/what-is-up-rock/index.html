20 秒了解 Up Rock

Up Rock 是一种来自纽约布鲁克林的斗舞。两位 rocker 伴着 Funk 与 Soul（放克与灵魂乐）唱片正面对决，随音乐即兴发挥：burn or get burned，不 burn 对方，就被对方 burn。

burn 是 rocker 的个人手势，从音乐里取来，冲着对手去，但不碰到对方。

三个动作

  • Freestyle 两次进攻之间，踩着节拍自由舞动。
  • Jerk 随音乐猛然发力的身体动作，常常朝地面往下沉。这是最基本的动作。
  • Burn rocker 从音乐里取来的个人手势，冲着对手去，但不碰到对方。

一场斗舞怎么进行

  1. 列队 一对一，或舞团对舞团，在 Apache Line 里面对面站好。
  2. 放唱片 斗舞持续整首歌。
  3. 即兴 没有固定的轮次。每位 rocker 都随音乐即兴，每一次 burn 都要求对方回应：burn or get burned。
  4. 绝不接触 不允许有身体接触。burn 是一个手势，绝不是一拳。
  5. 赢下来 Mighty Mike 回忆，他第一次参加 rock 斗舞时，大家看的是 freestyle、jerk 和 burn。把这一切做得最好的 rocker 获胜：靠创造力和对音乐的理解，而不是比谁亮出的“武器”最多，也不是比谁更会嘲弄对方。

我们的理解是：用真本事回应挑战。你可以寸步不让，同时尊重站在你对面的人。

rocker 之间是否有过身体接触，说法不一。有人回忆，早期的 rocking 是全接触的。据一位老前辈说，各个舞团定下不许接触的规矩，就是为了让斗舞不至于演变成打架。

音乐

Funk 与 Soul 唱片，从第一小节跳到最后一小节。布鲁克林的 DJ 会把唱片混接、串在一起，而不是只搓 break 那一段。具体唱片见音乐页。

Up Rock 还是 breaking？

布鲁克林的老一辈把 Up Rock 视为一门独立的舞蹈。它和 breaking 里的 Top Rock 有什么不同，请看 Up Rock 就是 Top Rock 吗？一页。

起源

Bushwick · Brooklyn

Up Rock 于20世纪60年代末诞生于布鲁克林的 Bushwick（布什维克）。它由两位舞者创造：Rubberband Man 和 Apache，两人在街头玩耍、找乐子时琢磨出了这门舞。Rubberband 也跳别的舞，还在其他舞种的比赛里屡屡获胜；Apache 则是那个爱开玩笑的人。Rubberband Man 已经离开了我们。

它的灵感来自街头帮派之间的斗殴。起初，rocker 们用街头打架的典型手势来模仿这些斗殴；随着反复练习，舞蹈里加入了对音乐的诠释和手势玩笑，比如嘲弄对手，或者拿唱片里的乐器和歌词逗乐，最终打磨成一种独立的舞蹈风格。很多时候，帮派斗殴变成了 Apache Line：用斗舞代替暴力。

几十年后，它走向了世界。如今在俄罗斯、波兰、日本、韩国和台湾等地都有 rocker 和舞团。每个日期及其出处都列在历史时间线上。

Rock、rocking、rock dance

同一种舞，好几个名字。早期的 rocker 多半说 rock 或 rocking。在 Bushwick，它也叫 rock dance。布鲁克林以外的人管它叫 Brooklyn rock。

Up Rock 和 uprocking 这两个叫法出现得更晚：

圈外人把“rocking”当成了摇滚乐的舞蹈，于是名字改成了“uprocking”。同一种舞，新的名字。

新名字是什么时候叫开的，说法不一。文字记载的时间从60年代末到1980至1981年不等。老前辈们把它和摇滚乐迷联系在一起：这些人跑来 rock contest，以为能看到乐队。有一种说法称，这些乐迷是在 Ridgewood，有人在那里告诉他们，这是 up rock。

Ridgewood 是皇后区的一个街区，紧挨着 Bushwick。
