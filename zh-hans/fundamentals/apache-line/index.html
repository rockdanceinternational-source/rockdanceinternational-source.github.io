Up Rock 的 Apache Line

Apache Line 是 Up Rock 的斗舞队形：两排 rocker 面对面，隔着中间的空当过招，一对一或舞团对舞团。这里讲它怎样进行、唯一一条铁规，以及关于它从何而来的几种说法。

  1. Apache Line 是什么
  2. 队列里的斗舞怎么进行

在 Up Rock 街舞里，Apache Line 是一种斗舞队形。本站提到这个词时，指的从来不是排舞（line dance）。

Apache Line 是什么

两排 rocker 面对面站着，一边是舞团，另一边是他们的对手。一位 rocker 和正对面的对手斗舞，或者整个舞团和另一个舞团斗舞。breaking 在圆圈里斗舞，Up Rock 则在一条线上斗舞。

很多时候，帮派斗殴变成了 Apache Line：同样是正面对峙，换成了斗舞，而不是暴力。

我们的理解是：一条共同遵守的规矩，让对手之间可以较量而不伤害彼此。歌放完了，这份尊重也要留着。

队列并不是唯一的形式：街头斗舞也会面对面直接进行。

更多细节

没人知道是谁最先想出这种队列，关于它的起源也说法不一。好几种说法把它和帮派的入会仪式联系起来：新人得从两排成员中间穿过去。按 Ralph Casanova 的讲法，成员们会用链条和棍子打他。只有 Ralph 提到：一位活动策划人把队列引进了70年代布鲁克林的 rock contest，好让每位 rocker 都待在自己那一边、互不接触，因为队列能防止打架。

队列里的斗舞怎么进行

  1. 列队。 两排人面对面，每位 rocker 对着一个对手。
  2. 放完整首歌。 斗舞持续整张唱片。
  3. 跟着音乐走。 两个 break 之间跳 Freestyle 或 burn，到了 break 上做一个 jerk 或 burn。
  4. 拍肩换人。 rocker 守住自己的位置，直到队友拍拍他的肩膀接替上场，或者直到对手撑不下去。拍肩是对两位 rocker 的尊重。

按 Break Easy 的说法，队列也用来考验新成员。新人从中间走过，一个接一个地和舞团里的每位 rocker 斗舞，在 freestyle、jerk 和 burn 里都要守住章法。一路斗着舞走完这条线，就是证明你会跳的时候。

队列可以很长。据 Dynasty Rockers 网站的说法，70年代末的一些比赛，一条线上同时有50多位 rocker 在斗舞。没有任何资料规定一条线该有多少人。日本杂志“Weekly UPROCK MAG”指出，如今队列主要用作 rocking 斗舞的预选赛。

规则

不许接触

大多数说法都只给出一条铁规：不许接触。burn 看起来可能像出拳或捅刀，但都在碰到之前停住。

碰到对方的 rocker 得不到分数，那个 burn 也不算；身体接触通常说明经验不足。据 Ralph Casanova 说，在舞团之间（与帮派不同），不能越过那条线，也不能互相碰触。Break Easy 说，rocking 起初是全接触的舞蹈，手会打到对手胸口，后来才改变。

谁赢

由谁来判，就没那么确定了。Mighty Mike 记得，当年一切都由观众决定；Ralph Casanova 回忆说，Apache Line 由 Rubberband 拍肩来判定。Mighty Mike 第一次参加 rock 斗舞时，大家要看的是 freestyle、jerk 和 burn。

Break Easy 认为，斗舞其实没有输家，因为赢靠的是对音乐的理解和舞蹈的风格。但当时确实有比赛和头衔，舞团之间还会拿彼此的衬衫做赌注来斗舞。
