Up Rock 的四项基本功

Up Rock 建立在四项基本功之上。三项是动作：freestyle、jerk 和 burn。第四项是 rocker 斗舞时的队形：Apache Line。这里从零讲起每一项，以及它们怎样配合唱片。

本页目录

  1. Freestyle
  2. Jerk
  3. Burn
  4. Apache Line
  5. 它们怎样配合唱片
基本功 是什么
Freestyle 两次进攻之间，踩着节拍自由舞动
Jerk 最基本的动作：随音乐猛然发力的身体动作，常常朝地面往下沉
Burn rocker 从音乐里取来的个人手势，冲着对手去，但不碰到对方
Apache Line 两排面对面的 rocker，斗舞就在这里进行

Freestyle、jerk 和 burn 过去是、现在仍是这门舞蹈的三大动作。斗舞在 Apache Line 里进行。分成四项，是我们的归纳。

Freestyle

Freestyle 是两次进攻之间踩着节拍的自由舞动。在 Little Ed 看来，它就是不带 burn 的 rocking；Break Easy 则说，在 freestyle 里照样可以 burn。

它永远不会跳成一模一样的两遍，因为它来自感觉和表达。

光有 burn 是不够的。再好的 burner 也得学会 freestyle，学会跟着整张唱片跳。

我们的理解是：先打好基础，再想着惊艳别人。拿出你自己的回应，而不是照搬别人的。

Jerk

Jerk 是最基本的动作：一个随音乐猛然发力的身体动作，常常朝地面往下沉。据一位老前辈说，在当年，凡是跳舞的人都在做 jerk。一个 jerk 的数法是：1, 2, 3 and 4。

难点在于时机。jerk 要落在唱片的某个点上，放错了位置，一眼就看得出来。

我们的理解是：先听，再动。练习专注，然后选准你的时机。

jerk 的种类很多：back jerk 和 double jerk，power jerk、soft jerk 和 bow jerk。Tiny Love 要求评委看的是完整的 jerk，而不是只做四分之一的 jerk。

更多细节

jerk 从哪里来，说法不一。一种说法认为它出自 Bushwick。一位 rocker 把他第一次见到 jerk 的日子定在1974年10月11日或12日。也有人说1976年以前根本没有 jerk，或者说他们在1975年或1976年第一次看到这门舞时还没有 jerk。历史页把这些日期都标在了时间线上。

Burn

burn 是一个冲着对手去的手势，但不碰到对方。它可以比划成砍他、刺他、开枪把他撂倒，或者把他折成两半。但 burn 远不只是模仿打架：它是每位 rocker 在手势上的创造力。深谙音乐的 rocker 能读懂唱片，并用自己独有的手势去诠释它。

burn 起初是对街头斗殴的模仿，用的是街头打架的手势。随着这门舞蹈不断练习、不断成长，rocker 们加入了对音乐的诠释和手势玩笑：嘲弄对手，或者拿唱片里的乐器和歌词做些滑稽的动作。它就是这样变成一种舞蹈风格的。

它不一定非得是武器，虽然人们有时以为 burn 就得是枪或刀：掏出一把梳子朝某人一弹，也是 burn。rocker 从唱片里的一个声音、一个词学到的任何东西，都可以变成 burn。而且它终究是舞蹈。burn 必须是跳着做出来的。获胜的 rocker 是把这一切做得最好的人，而不是亮出“武器”最多的人，也不是靠玩笑或攻击性去羞辱对方的人。

每一个 burn 都应该是新的：赢靠的是创造力，不是重复。

burn 不是 jerk，尽管很多人把两者当成一回事。以 burn 见长的 rocker 被称为 burner。这个词是60年代末到70年代的街头老话，那时人们会说自己 burn 了、或者“烤”了某个人。

Apache Line

Apache Line 是斗舞进行的地方：两排 rocker 面对面站着，一位 rocker 对另一位，或舞团对舞团。breaking 在圆圈里斗舞，Up Rock 则在一条线上斗舞。

在队列中间，两位对手随音乐斗舞，用 freestyle、jerk 和 burn 过招，没有身体接触。每位 rocker 都守住自己的位置，直到队友拍拍他的肩膀接替上场，或者直到对手撑不下去。拍肩是对两位 rocker 的尊重。

它怎样进行、有哪些规则、从何而来，请看 Apache Line 页。

它们怎样配合唱片

一场斗舞从头到尾跟着唱片走。

在 break 上

break 是唱片里的纯器乐段或鼓点段，在 Up Rock 里，这是进攻的时刻。据一位老前辈说，有些帮派甚至直接管这门舞叫“the break”，因为他们就等着这一段互相 burn。

两个 break 之间

在 break 到来之前，rocker 们跳 freestyle。按规则，这时也可以 burn。

整张唱片

一场 rock 斗舞持续整张唱片。Up Rock 用的是完整的音乐，而 breaking 是身体在一首歌的 break 段里的运动（通常30到60秒）。这很考验体力。一张唱片短则三四分钟，长则十到十五分钟，rocker 们还可能连着跳好几张。

rocker 们还会把歌曲演出来，把歌词和声音变成对付对手的武器，用音乐、一句歌词或一个声音营造出讲故事的错觉。遇到没有歌词的唱片，就跟着音效走。rocker 们点名的唱片见音乐页。

Burn or get burned

没有固定的轮次。rocker 们从第一小节到最后一小节都随音乐即兴，而一个 burn 必须得到回应：有人 burn 了你，你就得回敬一招，压过他的 burn。Burn or get burned，不 burn 对方，就被对方 burn。
