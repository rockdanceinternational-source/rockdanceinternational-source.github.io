Up Rock 的 Apache Line

Apache Line 是 Up Rock 的對戰隊形：兩列 rocker 面對面，隔著中間的空間尬舞，一對一或舞團對舞團。這裡介紹它怎麼進行、它唯一一條鐵律，以及關於它起源的各種說法。

  1. Apache Line 是什麼
  2. 隊列裡的 battle 怎麼進行

在 uprock 這支舞裡，Apache Line 是一種對戰隊形。在本網站，這個詞從來不是指排舞（line dance）。

Apache Line 是什麼

兩列 rocker 面對面，舞團在一邊，對手在另一邊。一位 rocker 跟正對面的對手 battle，或整個舞團跟另一個舞團 battle。Up Rock 排成一列對戰，breaking 則圍成圓圈對戰。

很多時候，幫派鬥毆變成了 Apache Line：一樣是面對面對峙，只是變成尬舞，而不是暴力。

我們的解讀：一條大家都遵守的規則，讓對手可以互相較量而不傷害彼此。歌結束之後，也把這份尊重帶著走。

排成一列並不是唯一的方式：街頭的 battle 也會一對一面對面進行。

更多細節

沒有人知道最早是誰想出這個隊列，關於它的起源也說法不一。有好幾種說法把它跟幫派的入會儀式連在一起：新人必須穿過兩排成員。其中一個版本說，成員會用鐵鍊和棍子打他。只有一種說法，來自 Ralph Casanova：1970 年代有位主辦人把這個隊列帶進布魯克林的 rock contest，讓每位 rocker 待在自己那一邊，不准碰觸，因為隊列可以防止打架。

隊列裡的 battle 怎麼進行

  1. 排好隊形。 兩排面對面，每位 rocker 對著一位對手。
  2. 放完整首歌。 battle 持續整張唱片。
  3. 跟著音樂走。 兩段 break 之間跳 Freestyle 或 burn，break 上做 jerk 或 burn。
  4. 拍肩換人。 rocker 守住自己的位置，直到隊友拍他的肩膀接手，或直到對手撐不下去為止。拍肩是對雙方 rocker 的尊重。

照 Break Easy 的說法，這個隊列也用來考驗新成員。新人從中間走過，一個接一個跟舞團裡的每位 rocker battle，在 freestyle、jerk 和 burn 裡都要守住紀律。一路 battle 走完整條隊列，就是證明你會跳的地方。

隊列可以很長。根據 Dynasty Rockers 網站，1970 年代末的一些比賽，一條隊列裡同時有超過 50 位 rocker 在 battle。沒有任何資料規定一條隊列該有多少位 rocker。有一本 rocking 雜誌提到，這個隊列現在主要用作 rocking battle 的預賽。

規則

不准碰觸

大多數說法都提到同一條鐵律：不准碰觸。burn 看起來可能像出拳或捅刀，但都會在碰到之前停住。

碰到對方的 rocker 得不到分數，也不算 burn，而碰觸通常代表經驗不足。Ralph Casanova 說，在舞團之間（和幫派不同），你不能越過隊列，也不能碰到對方。Break Easy 說，rocking 一開始是全接觸的舞，手會打在對手胸口，後來才改變。

誰贏

由誰來判定，就沒那麼確定了。Mighty Mike 記得當年一切都由觀眾決定；Ralph Casanova 則記得 Rubberband 用拍肩的方式評判 Apache Line。Mighty Mike 第一次參加 rock battle 時，大家要看的是 freestyle、jerk 和 burn。

有一種看法認為，battle 其實沒有輸家，因為贏的是對音樂的了解和舞蹈的風格。不過，當年確實有比賽和頭銜，舞團之間也會賭上彼此的隊服來 battle。
